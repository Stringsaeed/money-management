# Database operational scripts

These files are operator tooling, not application runtime modules. Before
deleting one, check its package script and workflow caller. The production
Postgres path is documented in the [migration runbook](../../../docs/agents/postgres-migrations.md).

| Script(s)                                                                                                                                        | Status and purpose                                                                                       | What it does                                                                                                                                                                                                            | Consequence of deletion                                                                                                                                                                    |
| ------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `run-postgres-migration.mjs` + `run-postgres-migration.test.mjs`                                                                                 | **Current production path.** Avoids giving the Worker role ownership privileges.                         | Reads exact Drizzle journal tags from `0016` onward, rejects arbitrary SQL and old tags, computes a checksum, invokes `pscale sql --role admin`, and applies one locked transaction with a version/tag/checksum marker. | `migrate-postgres.yml` cannot apply future production migrations; the schema is not changed automatically. The test coverage for the safety boundary is also lost.                         |
| `verify-post-cutover-schema.mjs` + `verify-post-cutover-schema-lib.mjs` + `verify-post-cutover-schema.test.mjs`                                  | **Current deploy gate.** Keeps ordinary Worker deploys read-only.                                        | Reads PostgreSQL catalogs and validates the required `0011`-`0015` tables, columns, constraints, indexes, publication entries, and future migration markers.                                                            | `deploy-worker.yml` loses its strict schema preflight and the Worker deploy command fails because its verifier entrypoint is missing. The catalog contract is no longer regression-tested. |
| `import-d1-cutover.mjs` + `d1-cutover-lib.mjs` + `d1-cutover-lib.test.mjs`                                                                       | **Legacy one-off cutover.** Retained for the historical D1-to-PlanetScale import procedure.              | Plans or executes the explicitly authorized cutover, transforms SQLite values, derives stable IDs, computes parity digests, and can reset/import the allowlisted tables under mode/approval checks.                     | The historical import/recovery procedure cannot run from the repository. Deleting only the library also breaks the importer; deleting its test removes transform and digest coverage.      |
| `apply-z6-publication.mjs`                                                                                                                       | **Legacy one-off non-production setup.**                                                                 | Applies the Z6 publication/sequence SQL to an explicitly supplied database URL after the `non-production` approval guard, then prints publication tables.                                                               | The Z6 publication setup cannot be repeated through `pnpm --filter @trove/db apply:z6-publication`; runtime code is unaffected.                                                            |
| `inspect-powersync-slots.mjs`                                                                                                                    | **Read-only diagnostic.**                                                                                | Reads replication-slot and replica state, including WAL lag, and prints a timestamped JSON snapshot.                                                                                                                    | Operators lose the repository-supported PowerSync slot diagnostic; runtime code is unaffected.                                                                                             |
| `ensure-post-cutover-schema.mjs` + `ensure-post-cutover-schema-lib.mjs` + `ensure-post-cutover-schema.test.mjs`                                  | **Legacy best-effort DDL.** Do not use for new production changes; the Worker deploy no longer calls it. | Attempts `0011`-`0015` statements with app credentials, soft-failing ownership errors and testing that legacy behavior.                                                                                                 | The legacy `ensure:post-cutover-schema` command and its soft-fail regression tests disappear. The current runner/verifier path is unaffected.                                              |
| `ensure-user-memberships-reconciled-at.mjs` + `ensure-user-memberships-reconciled-at-lib.mjs` + `ensure-user-memberships-reconciled-at.test.mjs` | **Legacy best-effort DDL.** No production workflow calls it.                                             | Attempts the single `user.memberships_reconciled_at` column alteration with app credentials, then checks presence while soft-failing ownership errors.                                                                  | The legacy `ensure:user-memberships-reconciled-at` package command and its tests disappear; the current runner/verifier path is unaffected.                                                |

The `*-lib.mjs` files are testable helpers for their paired entrypoints; their
`*.test.mjs` files do not change production state. The two `ensure-*` groups are
historical compatibility tooling, not an approval path for future schema
changes. The checked-in journal and protected migration workflow are the only
supported route for new production DDL.
